# Fonts

Bundled so the game and the manual look the same offline. All seven are licensed under the SIL Open Font License 1.1;
each license text is next to its font.

| File | Font | Used for | Source |
|---|---|---|---|
| Silkscreen-Regular.woff2 | Silkscreen | pixel labels and buttons (15 px and up) | https://github.com/googlefonts/silkscreen |
| PixelifySans-Variable.woff2 | Pixelify Sans | pixel titles and large numbers | https://github.com/eifetx/Pixelify-Sans |
| DepartureMono-Regular.woff2 | Departure Mono 1.500 | small labels (14 px and below) | https://github.com/rektdeckard/departure-mono |
| IBMPlexSans-Variable.woff2 | IBM Plex Sans | long, readable text | https://github.com/IBM/plex |
| CrimsonPro-Variable.woff2, CrimsonPro-Italic-Variable.woff2 | Crimson Pro | manual body text | https://github.com/Fonthausen/CrimsonPro |
| Montserrat-Variable.woff2 | Montserrat | manual headings | https://github.com/JulietaUla/Montserrat |
| Caveat-Variable.woff2 | Caveat | handwriting: manual notes, the sticky note on the bezel | https://github.com/googlefonts/caveat |

Latin subsets from Google Fonts, except Departure Mono (from its release).
